# QUO — Website

Sitio estático listo para GitHub + Vercel.

## Estructura
- `index.html`
- `styles.css`
- `script.js`
- `assets/`

## Deploy en GitHub
1. Crea un repositorio nuevo, por ejemplo `quo-eventos`.
2. Sube el contenido de esta carpeta a la raíz del repo.
3. Commit a `main`.

## Deploy en Vercel
1. En Vercel, `Add New > Project`.
2. Importa el repositorio de GitHub.
3. Framework preset: `Other`.
4. No necesitas Build Command.
5. Output Directory: déjalo vacío.
6. Deploy.

## Cambios rápidos
- Email: busca `marcelo@quo-io.com` en `index.html`.
- Instagram: busca `quo.eventos`.
- Textos de proyectos: sección `#work`.
- Imágenes: reemplaza archivos dentro de `/assets` manteniendo el mismo nombre.

Diseño: dark corporate + electric blue + motion, pensado para sentirse premium, futurista y tecnológico.
